# Products CRUD - React + Apollo Client

Professional CRUD example using React, Apollo Client, GraphQL and Bootstrap.

## API

GraphQL endpoint:
`https://node-products-graphql-api.onrender.com/graphql`

## Features

- Fetch products with Apollo `useQuery`
- Create products with `useMutation`
- Update products with `useMutation`
- Delete products with Apollo cache update
- Edit/cancel form state with React Context
- Loading and error states
- Client-side validation
- Bootstrap responsive UI

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
