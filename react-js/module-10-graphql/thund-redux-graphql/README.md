# React Redux Toolkit + GraphQL Product CRUD

Professional React/Vite CRUD frontend using:

- React
- Redux Toolkit
- React Redux
- Axios
- Bootstrap 5
- GraphQL API

## API

`https://node-products-graphql-api.onrender.com/graphql`

## Product fields

- name
- price
- category
- quantity

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project expects the GraphQL API to expose `products`, `createProduct`, `updateProduct`, and `deleteProduct`.
