Basic HTML Questions

    1) What does HTML stand for?
    => HTML stands for HyperText Markup Language.

    2) What is the purpose of the <html> tag?
    => This tag defines the root of an HTML document. It contains all the HTML content of the webpage.

    3) What is the use of the <head> section in HTML?
    => This tag contains metadata about the webpage such as: title, link css, link js, metatags, favicon etc.

    4) What is the <title> tag used for?
    => title tag is used to set the title of the webpage, disply on browser tab and also used in SEO 

    5) What is the difference between <h1> and <h6>?
    => H1 tag used to define largest heading, H6 used to define smallest heading in webpage. 

    6) What is the use of the <p> tag?
    => this tag is used to define paregraph of text.

    7) What is an HTML attribute? Give two examples.
    => HTML attribute provide additional information about tag
        (1) <a href="url">Test</a>
        (2) <img src="img path">

    8) What is the purpose of the <br> tag?
    => this tag is used to break current line.

    9) What is the difference between <b> and <strong> tags?
    => both same make text bold in webpage.

    10) What does the <em> tag do?
    => this tag emphasizes text, disply text in italic format.

1) How do you create a hyperlink in HTML?
=> Syntax : <a href="url" > Link Caption <a> 
   Example : Click to Open Google Page 

2) What is the purpose of the href attribute?
=> href contains the URL or page link of the page you want to open.

3) How do you open a link in a new tab?
=> Use target="_blank" attribute inside the <a>

4) What is the purpose of the <img> tag?
=> img tag is used to disply image on webpage

5) What does the alt attribute do in an image?
=> alt attribute is used to disply text when image fail to loads.

6) What is the difference between absolute and relative URLs?
=> absolute url means full url of webpage including base url 
    i.e.  <a href="http://myproject/Contactus.php"> Contactus <a>

=> relative url means short url of webpage or excluding base url 
    i.e.  <a href="Contactus.php"> Contactus <a>

Semantic HTML

    
1) What is semantic HTML?
=> Semantic HTML means using HTML tags that clearly describe the meaning and structure of the content.

2) What is the use of <header>?

3) What is the use of <footer>
=> this tag represent bottom section of webpage. it mostly contains copyright, company information, social media links etc...

4) What does <section> represent?
=> this tag represent group of contants. like Homepage Section, About section, contactus section etc....

5) What does <article> represent?
=> this tag disply data or content in webpage

6) What is the use of <nav>?
=> this tag is used to define navigation link.
Example : <nav> 
            <a href="home"> Home <a>

            <a href="contactus"> Contactus <a>
          </nav>

   Home | About |  Contactus

HTML5 Concepts

=> this tag does not need to closing that tag
    Example : <hr>, <br>, <input>, <link>, <meta>, <img>, <p>

2) What is the <!DOCTYPE html> declaration?
=> inform to the browser that page content written in HTML.

3) What is the difference between block-level and inline elements?
=> block level elements means start on new line and that takes full length of width. in this type of elements contains one or more inline-elements.  
   inline elements means do not start on new line. that takes necessary length of widht. in this type of elements generaly not written block elements. 

4) Name 5 block-level HTML elements.
=>  <div>, <p>, <h1>, <h6>, <section>

5) Name 5 inline HTML elements.
=>  <a>, <img>, <strong>, <em>, <sub>, <sup>  

6) What is the purpose of the <meta> tag?
